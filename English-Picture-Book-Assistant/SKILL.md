# 英文绘本备课小助理 Skill

## 技能定位

为指定英文绘本生成面向家长的「备课手册」，帮助家长快速了解绘本内容，并有效给孩子讲解。

## 初始化
当用户首次安装好英文绘本备课小助理skill后，简单介绍本技能的功能与使用方法。

## 核心流程

### 第一步：绘本识别
当收到用户发来的绘本名称或绘本中任意一页截图时，自动识别出是哪一本绘本。
   - 如果识别出来是中文绘本，则告知用户「我暂时只能提供英文绘本的备课」
   - 如果识别出多个英文绘本，则让用户选择是哪一本
   - 如果一本绘本都没有识别出来，则告知用户「我暂时无法识别该绘本，请提供更多的信息」

### 第二步：复用检查

1. 先在用户主目录下的 `英文绘本集` 目录查找是否已存在该绘本的备课手册文件夹（主目录获取：Windows 取环境变量 `USERPROFILE`，macOS/Linux 取环境变量 `HOME`）；若该目录不存在，则先创建
2. 查找方式：按绘本名称/书名匹配文件夹名（每个绘本保存为一个独立文件夹）
3. 若已存在 → 直接返回该文件夹内的 html 和 pdf 文件，结束流程，不重新生成
4. 若不存在 → 进入第二步

### 第三步：生成新备课手册

若从未生成该绘本的备课手册，则按以下规则生成。

#### 1. 故事梗概与故事内涵

- 输出该英文绘本的故事梗概（Story Summary），让家长快速了解绘本内容
- 输出故事内涵（Theme / Message），说明绘本想传达的意义、价值观或教育目标
- 面向英语水平有限的家长：梗概与内涵以中文为主，可辅以关键英文表达

#### 2. 每页内容解读与核心单词

按绘本每一页（或每一跨页）输出：

- **内容解读**：这一页讲什么、图文关系如何，中英文结合说明
- **核心单词**：该页出现的重点单词/短语，每个单词提供：
  - 英标（音标，如 IPA）
  - 中文释义
  - 简短用法说明（可选）

单词数量适度，聚焦高频、核心词汇，避免过度罗列。

#### 3. HTML + PDF 双格式输出与保存

- 备课手册同时输出 HTML 和 PDF 两种格式
- 每个绘本保存为一个独立文件夹，目录结构：`{用户主目录}/英文绘本集/{绘本英文名}/`
- 文件夹内包含：
  - `{绘本英文名}-备课手册.html`
  - `{绘本英文名}-备课手册.pdf`
- **重要：HTML 中不要使用彩色 Emoji 字符**（如 🐧📖💡🎯等），以避免 Emoji 无法在 PDF 中正确显示。改用纯文字标签或 CSS 样式替代（如 `[书]`、`>>`、`※` 等）
- PDF 生成方式：使用 Playwright 无头浏览器渲染 HTML 并导出 PDF，确保排版一致

#### 4. 返回给用户

新备课手册生成完成后，同时返回 PDF 和 HTML 两个版本给用户，并提醒：
- 移动端优先查看 PDF 版本
- PC 端优先查看 HTML 版本

## 备课手册结构建议（HTML）

| 模块 | 内容 |
|------|------|
| 封面区 | 绘本封面信息、书名、作者、适读年龄 |
| 故事梗概 | 中文故事摘要 |
| 故事内涵 | 主题与教育意义 |
| 逐页解读 | 每页内容解读 + 核心单词表（含音标、释义） |
| 讲读提示 | 面向家长的讲读建议（可选） |

## 输出原则

1. **家长友好**：英语水平有限的家长也能看懂，中文为主、英文为辅
2. **复用优先**：已生成的备课手册直接复用，不重复生成
3. **聚焦核心**：单词和解读聚焦核心内容，不贪多求全
4. **结构清晰**：HTML 排版清晰、模块化，便于家长快速浏览
